## id: NIT-119 auditor: audit severity: advisory category: conventions area: .goreleaser.yaml status: open found: 2026-07-08

# .goreleaser.yaml uses the deprecated brews property

## Problem

`goreleaser check` reports the configuration valid but using the
deprecated `brews` property.

## Evidence

`goreleaser check` (v2.16.0): "DEPRECATED: brews should not be
used anymore"; exits non-zero on deprecations.

## Impact

A future GoReleaser major will reject the config; release pipeline
breaks at that upgrade.

## Fix

Migrate `brews` to `homebrew_casks` per
https://goreleaser.com/deprecations#brews and re-run `goreleaser check`.
